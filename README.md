🚀 ReactFullTutorial

A complete React + Vite setup with hot module replacement (HMR), ESLint rules, and room for scaling into a full-stack app.
This project serves as a base for learning or building production-ready React applications with speed and flexibility.

⚡ Tech Stack

React 18 — Modern UI library

Vite — Lightning-fast bundler and dev server

ESLint — Code quality and linting

Tailwind CSS (optional) — Rapid styling (add if used)

Node.js — Runtime for development

📦 Installation & Setup

Clone the repository

git clone https://github.com/<your-username>/ReactFullTutorial.git
cd ReactFullTutorial

Install Dependencies

npm install

Run the development server

npm run dev

Then open your browser and navigate to:

http://localhost:5173

🔌 Plugins

Two official plugins are supported for Fast Refresh:

@vitejs/plugin-react

→ Uses Babel or oxc for fast refresh.

@vitejs/plugin-react-swc

→ Uses SWC for even faster performance.

🧠 React Compiler (Optional)

The React Compiler is disabled by default due to its performance impact during development.
To enable it, check the official React Compiler documentation
.

🧹 ESLint Configuration

If you’re developing for production, we recommend using TypeScript with type-aware linting.
You can refer to the official React + TypeScript Vite Template

and use typescript-eslint
.

🧰 Available Scripts
Command Description
npm run dev Start the dev server with HMR
npm run build Build for production
npm run preview Locally preview the production build
npm run lint Run ESLint checks
